# Open Food Facts tags → our categories

Hand-written mapping of Open Food Facts (OFF) category tags to our 183 categories: `tools/categories/off_map.py` (rules in its header).
This file is generated by `stages/05-category-model/build_off_train.py`.

**Use:**
1. Training examples for the category model (stage 05): real packaged products instead of only USDA's generic foods.
2. Later: a direct label for OFF products in the catalogue whose tags are clear.

## Coverage (2026-11-18, OFF dump with 4,906,869 products)

- **Mapped tags:** 1,571 (1,371 strong, 200 weak) + 14 baby tags.
- **Products with category tags:** 1,967,398.
- **Labelled:** 1,392,179 (71%): strong tag 1,027,756 · weak tag only 360,436 · baby 3,987.
- **Skipped:** no mapped tag 518,063 · conflicting tags 38,768 · non-food 11,023 · unclear (blocked) 3,994 · baby, unclear 3,371.
- **Training examples:** up to 1000 per category, English name, de-duplicated, never a test-sample product: **108,240** in 171 categories.
- **Greek training examples** (since 2026-11-18): up to 1000 more per category from Greek names: **1,307** in 115 categories. One Greek name in ten is held out: **98** products with only a Greek name form the Greek test set (`out/greek_test.json`).
